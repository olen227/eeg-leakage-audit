# Аудит утечки данных при обнаружении эпилептических приступов по ЭЭГ

Программный модуль, измеряющий, насколько качество детектора приступов завышено утечкой
данных при оценке, и раскладывающий это завышение на раздельно измеримые источники.

Код магистерской ВКР. Текст работы, результаты прогонов и рисунки в репозиторий не входят.

| Протокол | Обучающая часть | Открытый канал утечки |
| --- | --- | --- |
| P0 | всё, кроме оценочных окон | почти-дубли смежных окон |
| P1 | без окон оценочных файлов | тот же пациент |
| P1e | P1 + эмбарго 60 с по абсолютному времени | остаточная временная смежность снята |
| P2 | вынесенная идентичность исключена целиком | честная оценка |

Разложение точно по построению: слагаемые образуют телескопическую сумму разностей
соседних протоколов.

## Запуск

```bash
python stend/runs_v2/run_audit.py --cache <каталог набора> --name <имя>
```

Набор подаётся каталогом с тремя файлами (`X_raw.npy`, `meta.npz`, `cache_meta.json`);
контракт описан в `stend/runs_v2/dataset_contract.py`.

Модуль снабжён проверкой применимости, пороги которой выведены из измерений:

- идентичностей < 6 — порог значимости 0,05 недостижим арифметически;
- приступных окон на фолд < 30 — F1 неустойчива;
- записей на идентичность < 2 — покомпонентное разложение вырождается;
- прогонов < 3 — вклады компонентов приводить нельзя.

При нарушении условий модуль выдаёт числа и рядом объясняет, почему им нельзя верить.
Отдельно он сообщает о вырождении ступени каскада: если обучающие части соседних
протоколов совпали, соответствующий вклад равен нулю по построению, а не по результату
измерения, и молча приводить его нельзя.

Окна без абсолютного времени (`t_abs = NaN`) остаются в обучающей части: эмбарго к ним
не применяется, как и предписывает контракт. Наивная запись `dist >= embargo_sec` даёт на
`NaN` ложь и удалила бы их все — в CHB-MIT это обратило бы вклад перекрытия пациентов
в ноль у субъекта chb24, лишённого разметки времени в исходном наборе.

## Устройство

| Путь | Содержание |
| --- | --- |
| `stend/runs_v2/run_audit.py` | точка входа: весь аудит одной командой |
| `stend/runs_v2/protocols.py` | построение фолдов, каскад протоколов, эмбарго |
| `stend/runs_v2/run_decomposition.py` | прогон каскада и разложение завышения |
| `stend/runs_v2/dataset_contract.py` | контракт входных данных и пороги применимости |
| `stend/runs_v2/detector_v2.py` | детектор приступов с настраиваемой ёмкостью |
| `stend/runs_v2/run_stats.py` | доверительные интервалы и проверка значимости |
| `stend/runs_v2/run_hidden_duplicate.py` | вклад скрытой повторной регистрации пациента |
| `stend/runs_v2/build_cache_*.py` | приведение наборов CHB-MIT, Siena, Helsinki к контракту |
| `stend/vkr_eeg/` | общие настройки и работа с данными |
| `stend/runs/` | ранний каркас стенда, сохранён без изменений |

Прочие скрипты `run_*.py` выполняют отдельные измерения: усреднение по инициализациям,
устойчивость к способу счёта, зависимость от ёмкости модели, событийную оценку по
стандарту SzCORE, обнаружение дублей, объяснимость.

## Данные

В репозиторий не входят. Используются открытые наборы:

- CHB-MIT Scalp EEG Database — PhysioNet, DOI 10.13026/C2K01R
- Siena Scalp EEG Database — PhysioNet, DOI 10.13026/5d4a-j060
- Helsinki neonatal EEG — Stevenson et al., Scientific Data 6:190039 (2019)

Пути задаются переменными окружения `VKR_DATA_ROOT` и `VKR_CACHE_ROOT`.


## Окружение

Версии библиотек — `environment.txt` и `environment_freeze.txt`. Python 3.12.
